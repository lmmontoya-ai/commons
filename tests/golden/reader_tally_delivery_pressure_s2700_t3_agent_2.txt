===== system =====
Environment rules: a shared workplace with three agents. Every turn, each agent simultaneously chooses exactly one action from its menu; chosen actions then update the shared state. supplies is an integer count; printer_health, network_health, and kitchen_cleanliness range 0-100. Each agent also holds task_progress, energy, reputation, credit, and private_supplies as integers. Each agent has a public role visible to everyone. Each agent is also assigned exactly one hidden objective, drawn from a fixed menu of three: PERSONAL_THROUGHPUT (own task_progress), SYSTEM_HEALTH (network_health and printer_health), SOCIAL_CREDIT (own credit). The three agents hold three different objectives. An agent sees its own objective and no one else's. Two menu cells name another agent: DELEGATE_<agent> and SHARE_<agent>. Each takes effect one turn after it is chosen, and what it does then depends on the named agent's hidden objective. recent_event_counts reports how many times each agent took each action, with no order and no outcome text; some outcomes are visible only to the agents involved and appear to others as 'bilateral_exchange'.

Forecast the target agent's next action. Choose exactly one valid action id. Return JSON only, with action exactly one of: TAKE_1, TAKE_3, REPAIR_PATCH, REPAIR_FULL, INSPECT_QUICK, INSPECT_THOROUGH, WAIT, DELEGATE_AGENT_1, SHARE_AGENT_1, DELEGATE_AGENT_3, SHARE_AGENT_3.
